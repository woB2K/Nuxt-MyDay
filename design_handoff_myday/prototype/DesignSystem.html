MyDay · Design System

A calm, focused dark interface for managing your day — tasks and money in one place.

Mobile-first, dark-by-default. Tokens for color, type, spacing, and motion. Components that compose. Inspired by iOS, Linear, and Apple Reminders — without copying any of them.

390 × 844 base Dark theme primary SF Pro Display + Inter 16px base unit Spring motion

Colors

Haptics & motion

Spring easings, short durations. Every gesture earns a tactile response.

Spring

ease-out: cubic-bezier(.22, 1, .36, 1)
ease-spring: cubic-bezier(.34, 1.56, .64, 1)
dur-fast: 150ms
dur-base: 240ms
dur-slow: 360ms
dur-sheet: 420ms

Haptic feedback

light — toggle complete
medium — delete, destructive
heavy — long press
success — transaction saved
warning — overspend
error — invalid input

Gesture spec

Swipe right task → complete (haptic: success)
Swipe left task → delete (haptic: medium)
Threshold: 80px, rubber-band past 160
Spring-back duration: 240ms

Tailwind config

Drop into tailwind.config.js as your design tokens.

// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        bg:       '#0F0F14',
        elev1:    '#15151C',
        elev2:    '#1C1C25',
        elev3:    '#26262F',
        ink: {
          DEFAULT: '#F4F4F7',
          dim:     '#A1A1AA',
          mute:    '#6B6B75',
          ghost:   '#3F3F47',
        },
        accent: {
          DEFAULT: '#A78BFA',  // violet
          soft:    'rgba(167,139,250,0.14)',
          ink:     '#0F0F14',
        },
        success: '#34D399',
        warning: '#FBBF24',
        danger:  '#F87171',

      },
      fontFamily: {
        display: ['-apple-system', '"SF Pro Display"', 'system-ui'],
        body:    ['Inter', '-apple-system', 'system-ui'],
      },
      fontSize: {
        hero:     ['56px', { lineHeight: '60px', letterSpacing: '-0.03em', fontWeight: 700 }],
        title1:   ['34px', { lineHeight: '40px', letterSpacing: '-0.02em', fontWeight: 700 }],
        title2:   ['28px', { lineHeight: '34px', letterSpacing: '-0.02em', fontWeight: 700 }],
        title3:   ['22px', { lineHeight: '28px', letterSpacing: '-0.01em', fontWeight: 600 }],
        headline: ['17px', { lineHeight: '22px', letterSpacing: '-0.01em', fontWeight: 600 }],
        body:     ['17px', { lineHeight: '24px', fontWeight: 400 }],
        callout:  ['16px', { lineHeight: '21px', fontWeight: 500 }],
        sub:      ['15px', { lineHeight: '20px', fontWeight: 400 }],
        footnote: ['13px', { lineHeight: '18px', fontWeight: 500 }],
        overline: ['11px', { lineHeight: '14px', letterSpacing: '0.08em', fontWeight: 600 }],
      },
      spacing: {
        '1':  '4px',   '2':  '8px',   '3':  '12px',
        '4':  '16px',  /* base */
        '5':  '20px',  '6':  '24px',  '7':  '28px',
        '8':  '32px',  '10': '40px',  '12': '48px',

        sm:   '8px',    // buttons
        md:   '12px',   // inputs
        lg:   '16px',   // cards

        '2xl': '24px', // sheet top corners

      boxShadow: {
        sm:   '0 1px 2px rgba(0,0,0,0.4)',
