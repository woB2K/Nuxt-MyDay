# 10.15 — статья на Хабр: план и факты

Пишет Максим, это план и выжимка фактов из репозитория на 25.10.2026, чтобы не искать их по коду.

## Заход

Не «я сделал ещё один трекер финансов», а история: семье нужен был общий бюджет и общий список дел, существующие приложения либо облачные и платные, либо self-hosted для одиночек. Получилось приложение, которое один технарь поднимает за пять минут, а остальные ставят на телефон как обычное.

## План

1. **Зачем** — задача семьи; почему не Дзен-мани/CoinKeeper (облако, нет задач и привычек) и не Firefly III/Actual (сильные финансы, но для одного и без «дня»).
2. **Что получилось** — скриншоты из `docs/screenshots/ru`, ссылка на демо. Три части: день (задачи, привычки, фокус), деньги семьи, копилка с целями.
3. **Семья как модель данных** — каждый пользователь всегда в семье хотя бы из себя, финансы принадлежат семье, задачи личные; что происходит при вступлении (склейка категорий по ключу) и выходе (уходящий забирает копию). Решения и отвергнутые варианты — `ARCHITECTURE.md` → «Семья».
4. **PWA вместо нативного приложения** — офлайн-запись траты на iOS, где выгруженное приложение стартует холодным: очередь в IndexedDB, клиентский `id`, чтобы повтор не задвоил запись, офлайн-сессия по запомненному профилю.
5. **Безопасность маленького self-host** — истории из ревью 14.10: `GET /%61pi/tasks` обходил auth-middleware и отдавал задачи всех пользователей; `X-Forwarded-For` и лимит входа; PIN-хеш, который уезжал клиенту. И находка CSP: все иконки в проде грузились со стороннего API.
6. **Self-host для чужих** — одна команда, Caddy с HTTPS, закрытая регистрация с исключением для первого аккаунта, сброс пароля без почты через CLI, импорт из Дзен-мани и CoinKeeper, мультиархитектурные образы для Raspberry Pi.
7. **Как писалось** — код пишет Claude Code по роадмапу, Максим ревьюит и принимает; правила в `CLAUDE.md`, решения в `ARCHITECTURE.md`. Что это дало и где пришлось поправлять.
8. **Что дальше** — фаза 7 (бюджеты, повторяющиеся операции), публичный инстанс только по спросу (фаза 11).

## Цифры

- Первый коммит — 8 мая 2026, к 25 октября — 195 коммитов, 8 релизов (v1.0.0 → v2.2.0).
- Код приложения — около 18,5 тыс. строк (`app/`, `server/`, `shared/`), тестов — около 15,5 тыс. строк.
- Тесты: 106 файлов юнит-тестов (850+ тестов), 17 файлов интеграционных против настоящего Postgres, 17 E2E-сценариев Playwright.
- 13 миграций базы.
- Стек: Nuxt 4, Vue 3, Prisma 7 (driver adapter), PostgreSQL 16, Tailwind 4, Nuxt UI, TanStack Query, Pinia, Zod, PWA.

Перепроверить числа перед публикацией: `git log --oneline | wc -l`, `pnpm test`, `ls tests/integration`.
